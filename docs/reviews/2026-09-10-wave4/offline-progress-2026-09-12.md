Wave 4 remains incomplete on `codex/personal-v1-w4-integration`, based on the verified Wave 3 merge `e1bcea18eaa18ad144bc3b03a4891d11ecdd9b06`. The current code is in isolated integration staging. This record does not claim a W4 commit, PR, merge, provider qualification or active worker.

The finite session coordinator now routes existing owned sources through the sole engine and account/risk/reconciliation publishers. It keeps immediate first-send tokens within one operation; restored receipts do not create new tokens. Lost acknowledgments and actual command-rejected acknowledgments preserve ordinary failure evidence and use the original attempt source to record UNKNOWN when the current lease and Stop state permit. An explicit independent registered-order observation is required to establish a definitive outcome. Financial observations are applied separately through the existing engine and coupled C/B/A transaction.

The account's cooperative Stop scope binds an exact Event to its original thread, rejects copied/conflicting scopes and samples again after all original final readbacks immediately before COMMIT. Once observed, Stop remains latched for that account instance. This is an in-process denial check: a later signal can race COMMIT, and a transient signal set and cleared between samples is not observed. Durable operational controls and the supervised process lifecycle remain separate boundaries.
