## Exclusive write ownership and shared contracts

One orchestrator allocates every implementation task against the current reviewed integration commit. At most three additional workers globally, including nested workers; no nested worker without an explicitly released slot. Wave 0 used exactly two collaboration workers, both read-only against code, each writing its own temporary specification directory. The orchestrator alone integrates canonical documents. No implementation app task, commit, migration, or code change was created.

The exact shared-file exclusions and writer assignments here take precedence over grouped lane hints in the supporting caller inventories. The following ownership is exclusive *within* each wave and transfers only at its integrated exit gate. A path listed as orchestrator-owned cannot be edited by a lane under a directory-wide assignment. New filenames are reserved targets, not existing implementation claims. Workers propose shared-file diffs for serialized integration; they do not allocate database migration identifiers themselves.

## Migration invariants and retirement gates

Preserve balanced append-only journal, FIFO lot economics, whole-share cash eligibility, settlement, action/correction identity and terminal open holdings. Preserve logical-order / attempt / fill separation, all-or-none reservations, latched uncertainty, owner/control generations and no automatic re-arm. Preserve time equality rejection, observed receipt history, causal feature fitting and no same-event signal fill.

The canonical historical/forward/live decision service is the reserved application `causal_engine.py`; the canonical pure daily risk entry is `daily_risk.py`, composing retained batch rules with a versioned producer snapshot. Existing golden/generic/Phase 3H and old advanced-risk entry points remain unchanged at W0 and are not three future product engines or three future risk policies. W2 passes pure semantics; W4 adds durable account serialization and reservation cutover.

New admission accepts only its declared research class with explicit assumptions. Old hashes/approvals/attempts are never upgraded by migration. Native lifecycle/signing/remote anchor, old Alpaca smoke, SIP/intraday metrics and externally unconstructible research-review prerequisites are superseded personal-v1 targets; their actual dependency edges remain in code until the mapped replacement gates pass. Preserve all historical migrations, runbooks, branch snapshots and unresolved native findings. Deleting tests requires demonstrating retained behavioral coverage first.

No W1 work begins automatically after this contract is frozen. The next orchestrator turn must receive scope authorization, verify source/doc manifests and allocate current exact paths against the same canonical plan.
